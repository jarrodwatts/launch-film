what replaced it. Read this before each notes round and before showing a cut. Most of these will be
rejected again, for any product, by anyone with taste.

## 2. The user's two code words

- **"Lazy"** means text on a background, or any default treatment: a caption over a shot, a plain
  pill, a stock layout. "I really don't like the text style of 'every market one chat', that feels
  very lazy, it should be it's own related secene that transitions nicely from the previous scene";
  "the text above it is lazy"; "the remaining last ~15 seconds just feels incredibly lazy". The fix is
  never a nicer font. It is a scene where the words come out of the motion before them.
- **"Slop"** (or "AI slop") means generated or generic decoration: a sticker, a generated blob or orb,
  a clip-art icon, a meaningless label. "the 'youre in' is ai slop"; "randomly generated slop". The
  fix is the real thing: the product's mark, a partner's logo, a literal proof of the result.

"Sloppy" is a third word, about execution: cut off, overlapping, clashing, cramped. The fix is the
frame checks in `launch-film:review`.

## 3. A repeated note means the named element was never changed

The orb icon came back three rounds running. Each time, Claude changed what was around it: a flat
blue header, a gloss, a ring. The user had named the top of the card, and in v5 spelled it out: "i.e.
change the icon". When a note comes back:

- read it literally and find the exact element it names;
- confirm on a still that this element is different, not its surroundings;
- say in your reply which element you changed.

The rule holds in reverse, too: something the user praised ("I love the transition") must survive
every rework.
